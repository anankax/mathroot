# 数根 · mathroot

初中数学错题复盘助手。**只问不答**——不问出你自己说出错在哪一步，它就不给答案。
右边配一块随讲随画的互动画板，图跟着话一点点长出来，动点能真的动起来。

线上地址：<https://anankax.github.io/mathroot/>

---

## 怎么用

1. 打开页面**直接就能用**——默认走内置的免费通道（智谱 GLM），不用注册、不用填 Key。
   想要更稳的，顶栏切到「用自己的 Key」，填一个自己的 DeepSeek Key
   （[在这里申请](https://platform.deepseek.com/api_keys)）。
   自己的 Key 只存在自己浏览器的 localStorage 里，**仓库和网页里都没有它**。
2. 把做错的题贴进去，或者**拍张照传上来**，说说你当时是怎么想的。它顺着你的思路问，不给答案。
3. 卡住了它会说"画出来看看"，右边的画板就出一条数轴给你当纸用——点要你自己标。

顶栏右边可以切 **教师演示模式**：这个模式可以画、可以讲、可以直接给答案，上课演示用。
存书签时带上 `#demo`（`…/mathroot/#demo`）就能直接进演示模式。画板右上角能切**平面 / 三维**，
立体几何、旋转、平移都在里面。

### 两条通道不是"同一件事快慢不同"

| | 免费体验（GLM） | 用自己的 Key（DeepSeek） |
|---|---|---|
| 要不要注册 | 不要 | 要 |
| 花谁的钱 | 不花钱 | 花自己的 |
| 上下文 | 小（按 token 裁历史） | 大（1M，不用裁） |
| 稳不稳 | **会排队**，尤其上传图片那一轮 | 稳 |
| 提示词 | 精简版（5121 字） | 全量版（11555 字） |

免费那条约 1/3 的概率会回一句"通道挤了"——那不是坏了，是免费池在限流。
等十几秒点气泡上的**「再试一次」**就行（照片和原话都还在，不用重新拍）。

## 两个模式的区别

| | 学生模式 | 教师演示模式 |
|---|---|---|
| 给不给答案 | **不给**，一个字都不给 | 给，而且讲透 |
| 画板 | 只出空底图，点要学生自己标 | 随便画，滑块、动点、动画都行 |
| 面向谁 | 学生自己复盘用 | 老师上课演示用 |

## 为什么是纯静态站

不用后端、不用服务器、不用打包。打开 `index.html` 就能跑，推到 GitHub Pages 就能上线。
- **DeepSeek 和智谱 GLM 都允许浏览器直连**（CORS 实测放行），所以不需要任何代理。
- **GeoGebra 官方嵌入脚本**（`deployggb.js`）给出完整的 `ggbApplet` 接口，
  于是画板是"我们自己的"，逐条下命令、控制动画都做得到。

> ⚠️ 代价：免费通道那颗 Key 是**明文写在 `js/config.js` 里**的（同「邰言邰语」那套取舍）。
> 免费池只影响他账号的可用性，**不产生费用**；想收紧就把 `SR.GLM_KEY` 清空，
> 页面会自动落回"请自带 Key"那一档，其余一切照常。

## 画板命令（提示词里教模型用的就是这套）

```ggb
#清空            把画板擦干净
数轴             横向数轴，只留尺子不留点
坐标系           带网格的坐标平面
A=(1,2)          其余按 GeoGebra 写法原样写
线段(A,B)        中英文命令名都收——见下面"中文命令要翻译"
#隐藏 t          藏起来
#播放 t          画板上冒出播放键，点它 t 动起来（讲动点用）
#暂停            停下来
```

**中文命令要翻译。** 这个 applet 的**界面是中文的，但 `evalCommand` 只认英文命令名**：
`交点(f,g)` 返回 false、什么都不建，`Intersect(f,g)` 才建得出点。所以提示词里照旧教中文
（老师看着自然、模型也愿意照抄），由 `js/board.js` 的 `CMD_MAP` 翻一道再发下去。
不翻的话 `线段`、`圆`、`多边形`、`中点`、`角`、`距离` 全会**一声不响地什么都不画**——
错误弹窗又被关掉了，课上没人会发现。加新命令记得往 `CMD_MAP` 里补，
再用 `node test/probe_zhcmd.cjs` 逐条验一遍（会真的在 applet 里建对象来判）。

### 为什么这份索引不能进仓库

它是**扫描出来的文件名和本机路径**，不含任何素材内容——但这就够不上站了。
往公开网页上一放，等于把学科网、出版社、别人的课程"我手上有哪些、标题叫什么"
摊开给所有人看，那本身也是那些素材的一部分。所以：

- **公开站上没有 `js/resource-index.js`**（不在仓库里），`js/resources.js` 探测不到，
  「素材」按钮就一直藏着（`display:none`），客户那边从头到尾看不到这个按钮。
- **索引只在本地加载**，而且是**点了按钮才去拿**（300 KB，不拖开机）。
- `test/probe_resources.cjs` 验的就是这两面：本机能筛出东西，**并且**用 CDP 把
  `js/resource-index.js` 拦掉之后按钮彻底消失。只验前一面的话，
  "客户看不到"就只是句没验过的假设——而它恰恰是这一档的底线。

素材本身（教材 PDF、学科网课件、上好课、葛老师的设计、胡小群）**一律不进仓库、不上站**，
理由和替代办法写在 `24-知识库\05-后备资源（本地素材索引·不随站发布）.md`。

✅ **已拍板（2026-10-02）：撤下公开站，但保留本机能力。**

原来 `js/textbook.js`（56 KB、78 处 `【书上原话】`）是**跟着仓库上站的**——公开站上
HTTP 200，谁都下得走；而 `index.html` 里那句"访客一个字都看不见"只在说界面。
按 `.gitignore` 里那条判据（"就算界面上不显示，文件本身也已经发出去了"），这条界线破了。

处理办法是**跟 `js/resource-index.js` 一个待遇**，不是删掉：

- 加进 `.gitignore`，`git rm --cached` 撤出仓库，**本机那份文件原样留着**；
- `js/kb.js` 里给这份语料标 `localOnly`，公开站上**连那一次请求都不发**
  （判法照抄 `js/resources.js` 的 `local()`：`localhost`/`127.0.0.1`/空 host/`file:`），
  所以控制台不会多一行 404——`kb.js` 顶上那句"别让 FILES 指向不存在的文件"还成立；
- 拿不到就退回"没检索到"那一档，**对话永远不被挡住**（这是这个模块原有的性质）。

结果：**本机翻教材照常，公开站上没有那份文件。**

⚠ **两件要说白的**：
1. 撤下来**不会**抹掉已经提交过的历史。仓库只要是公开的，`js/textbook.js` 仍然能从
   旧 commit 里翻出来（`github.com/<owner>/<repo>/blob/<旧 sha>/js/textbook.js`）。
   真要连历史一起清掉得改写历史（`filter-repo` 那类），代价是所有人的 clone 都作废——
   **判断是：不必。** 线上那个 URL 已经 404，这就够了。
2. 学生的提问一旦命中教材条目，**那几段原话仍然会随提示词发给模型**——这个搬不掉，
   模型要靠它答话。撤掉的只是"整份索引挂在网上任人下载"。
   （要让它在线上也彻底不落地，得把检索搬进云函数，那是下一步的事。）

## 知识库：两份语料，什么时候给、给谁会看

两份语料都只喂给模型，学生看不见、界面上也不出现。★ **但它们的公开性不一样，别当成一对看**：

| 语料 | 是什么 | 条数 | 公开站上有吗 |
|---|---|---|---|
| `js/textbook.js` | 苏科版教材索引（章节脉络 + **78 处【书上原话】**） | 118 | **没有**——课本原文，不进仓库，只在本机加载 |
| `js/zhuawen.js` | 追问条目库（按"学生说到哪儿了"分五档的追问问法）★ 真正的含金量 | 118 | 有——孔老师自己写的 |

三件事值得记：

1. **不在首屏。** 两份共 117 KB，原来挂在 `index.html` 的 `<script defer>` 上——首屏就得下、
   得解析，可它们真正派上用场是学生点「发送」那一刻。现在由 `js/kb.js` **按需**拿
   （第一次提问，或本机点开「知识库」面板）。`test/page_probe.cjs` 两件事都判：
   首屏确实没有、要用时装得上。只判前半句会放过"永远装不上"。
2. **召回用的不是"这一轮那句话"。** 学生十有八九不点知识点的名——"这题我不会""第二题"，
   这些话里一个知识点的字都没有，二元组一个都对不上，于是**永远召不回**。
   `SR.kb.queryFor` 把前几轮学生自己说的话一起当检索词（只取学生的、限长 240 字、给太多会被摊平）。
3. **有分数线，而且是量出来的。** 见下。

```bash
node test/probe_kb.cjs          # 召回的验收（A/A′/B/C/D 五组）
node test/probe_kb_scores.cjs   # 分数线怎么定的
```

本机顶栏有个**「知识库」按钮**（公开站上没有），打一句学生真会说的话，
就能看见召回了什么、各多少分、哪几条被分数线卡掉。

### 分数线为什么是 10 / 6，不是 3

原来条目库那条线是 `score < 3`，教材索引**根本没有线**。面板第一次打开就露了馅：
"这道题我不会，我算到一半就卡住了"——一个字的知识点都没有——照样召回了
「图形的变换·旋转(7.9)」，喂进了 system。**13 句泛泛的学生话漏进去 11 句。**

把 13 句点着知识点名的 + 13 句泛泛的放在一起量首条分数：

```
条目库：该召回 13.3 ~ 57.5   不该召回 0 ~ 7.9     → 线取 10
教材索引：该召回 8.0 ~ 28.3   不该召回 0 ~ 4.4     → 线取 6
```

两条教训比数字本身更要紧：

- **测试集里没有"最难的那一档"，量出来的线就是假的。** 第一版只测"绝对值化简的时候我不
  知道要不要变号"这种完整句子，分得漂漂亮亮（真话下限 20.8），差点把线定在 8。把**学生真会
  打的短话**（"绝对值""增长率""我不会画数轴"）加进去之后，真话下限掉到 13.3，天花板才露出来。
- **为什么不是刚好卡住 7.9 的 8**：`queryFor` 会把前几轮拼进来，而 BM25 是**累加**的。
  实测一个从头到尾只会说废话的学生，攒到第 5 轮首条分数从 7.9 涨到 **8.1**——定 8 那一轮就漏。
- **线宁可偏高。** 代价不对称：给错了是往 system 里塞一条八竿子打不着的条目，模型顺着它跑偏；
  没给就退回加知识库之前那一档，本来就是这个系统的默认样子。所以 `buildSystem` 里
  **没召到就一个字都不加**，那条 `if` 的反面就是"没召回到怎么办"这一档，别去补什么通用追问。

几个探针的退出码有讲究，别只看红绿：
- `probe_3d.cjs` 退出 **1** = "该过的"里有过不去的。它把用例分成两档：
  `want:true`（必须建出东西）和 `want:false`（**预期不过**，是把已知约束钉在明处——
  Prism/Pyramid 要的是多边形而非散点、3D 下只认英文命令名）。只有前一档算红绿。
- `probe_blank.cjs` 退出 **3** = 量坐标轴的尺子本身坏了（两个已知状态读不出差别），
  结论一个都不能信，先修仪器。
- `probe_png.cjs` 退出 **3** = 同一把"量右下角墨点"的尺子。它**同时**量两张图：
  没水印的原图（`toPNG`）和该有水印的导出图（`exportPNG`）。原图必须近似 0
  ——不然尺子是见谁都报有墨，两张都"有"的时候它分不出"烧了"和"没烧"。
  退出 1 = 原图干净、导出图却也没有墨，那才是真的没烧进去。

`probe_image.cjs` 现在是**三段证据分开报**，别把它们混成一句"红/绿"：
- **通道单独量一次**：绕开提示词，拿同一张图直接问"把图上的算式念出来"。
  念得出来才说明通道是通的。这一步红了，后面红绿都不用看，先修通道。
- **图送出去了吗**：直接读客户端**发出去的请求体**里有没有 `image_url`。这是硬证据。
- **越界点出错步 / 模型在允许名单**：判的是模型守没守住铁律第 7 条、以及有没有被悄悄降级。
- ⚠ 它**不**再用"模型复述没复述图上的东西"当判据了。守规矩的模型第一轮本来就只问一句
  "这道题你当时是怎么做的？"什么都不复述——拿复述当"送到了"，等于谁越界谁得分。
- **挑完图先量三样，一样都不能省**：图**在不在 DOM 里**（`len`）、**显没显示出来**
  （`#thumb` 的 computed display）、**是不是给学生的**（src 前缀）。三段是 AND 关系。
  2026-10-01 之前只判 `len`，于是缩略图明明 `display:none` 挂在屏幕上，
  探针把 `"thumb":"none"` 原样打印出来、**照样报通过**。打了数字却没判那个数字，等于没测。

`probe_fence.cjs` 那一行数字怎么看（学生模式那几格）：
- **回声 / 念叨 / 拦漏** 才是红绿。回声＝模型反过来演学生；念叨＝它在跟提示词说话；
  拦漏＝模型抄了提示词里的示范，**而出口过滤没拦住、学生真的看见了那些按钮**。
- **抄示范 / 漏命令** 只印出来当信息，不判红绿：小模型一定会抄示范（那是提示词里放着示范的代价），
  也一定会在被要求画图时掉围栏——两件事产品那头各有各的兜底（`chips.js` 的出口过滤、
  `render.js` 的删行），兜没兜住由那两个地方的探针负责。
- 每个计数器都会把命中的**原话**打出来（`↳ 回声原文：…`）。**数字红了先看原话再下结论**——
  这台仪器抓错过一次，详见下面"踩过的坑"。要每条原文就 `DUMP=1`，要含围栏的原始输出就 `DUMPRAW=1`。

`probe_image.cjs` / `probe_blank.cjs` 自己会点气泡上的「再试一次」重试，
顺带把"出错后照片还在不在、重发会不会把话重复说一遍"也一起验了。

`e2e.cjs` 与 `probe_fence.cjs` 会在运行时从 `~/.claude/settings.json` 现读一个 Key
塞进那个浏览器标签的 localStorage，**不写盘、不进仓库**。测完全程留意最后那句
「页面异常: 无」——有异常会在那儿列出来。

`test/` 里还躺着一批一次性探针（`probe_glm_*.cjs`、`probe_lean_cliff.cjs` 等）——
它们是**当时得出 `config.js` 里那些数字用的**（16K 上下文的上限、精简提示词的临界点、
429 会不会误伤别的模型），平时不用跑，留着是为了那些数字日后能被复查。
探针自己产生的中间文件一律叫 `test/_*`，由 `.gitignore` 挡住，不进仓库。

## 部署

`main` 分支根目录，`git push` 一两分钟生效。没有 CI、没有构建步骤。

**github.com 连不上的时候**（国内网络常见的连接重置，`git push` 和 `curl github.com`
都是 21 秒超时），`api.github.com` 往往还是通的，就用

```bash
node test/push_via_api.cjs        # 推 HEAD 到 origin/main
DRY=1 node test/push_via_api.cjs  # 只造对象、到改 ref 前停下，拿来核对
```

它绕开 git 的传输层，走 GitHub 的 Git Data API 自己拼 blob → tree → commit → ref，
身份／时间戳／树／父提交全从本地提交对象里读出来原样传过去。
跑完会**逐字节自检**：重造一颗提交、sha 必须和远端那颗一模一样，对不上就报错、
本地 refs 一个字都不改。远端不是快进关系它也会拒绝（`exit 4`）。

**它会改本地 HEAD 的 sha，这是设计好的，别慌。** `git commit` 造的提交正文末尾带一个换行，
GitHub 存的不带——树的字节完全一样，差的就是那一个字符，所以两颗 sha 天然不同。
脚本把本地 `refs/heads/main` 也指到远端那颗，两边才真是同一颗（每次推完 sha 都会变一次，
`git reflog` 里找得回旧的）。这一段它跑完会自己印出来说明。

两个实测的坑记在脚本注释里：API 要 ISO 的 `+08:00` 而 git 对象头写的是 `+0800`；
GET 回来的 `author.date` 显示成 `Z`（UTC），但对象里存的还是原来的时区——
照着显示值重造，sha 永远对不上。

## 踩过的坑

### 画板（GeoGebra）

- **必须用 `appName: 'classic'`。** 原先是 `'graphing'`（图形计算器），那是个精简版：
  `线段`、`圆`、`多边形`、`中点`、`中垂线`、`角`、`距离` **一条都建不出东西**，
  实测 14 条几何命令只过 4 条；换 classic 之后 14 条过 13 条。
- **`evalCommand` 只认英文命令名**（界面是中文的也没用）。见上面「中文命令要翻译」。
- **别用 `evalCommand` 调 `SetGridVisible`／`SetVisibleInView` 这类。** `setVisibleInView`
  这个方法**在这个 applet 里根本不存在**；命令写错时 GeoGebra 会弹一个「未知的指令」的
  **模态框糊在画板正中间**——公开课上弹这个就完了。数轴／坐标系改走真 API
  （`setAxesVisible` / `setGridVisible` / `setCoordSystem`），并在 `appletOnLoad` 里调
  `setErrorDialogsActive(false)` 兜底（命令写错时只记控制台，不弹框）。
- **`perspective:'G'` 这个启动参数不管用**，代数面板照样白占底下三分之一、滑块还在里头露出来。
  得等 `appletOnLoad` 之后再喊一声 `setPerspective('G')`。
- **`文本("...", true, true)` 这个两布尔的写法不合法**，必须给位置：`文本("∠A=40°", (2,3))`。
- **`getVisible('yAxis')` 不可靠**（明明藏住了它报 true）。判"画板上是不是空数轴"要读 XML：
  `ggbApplet.getXML()` 里的 `<axis id="0" … show="…">` 是 x 轴、`<axis id="1" … show="…">` 是 y 轴
  （GeoGebra 的 `AXIS_X=0`、`AXIS_Y=1`，**不是 1/2**）。空数轴 = x 为 `true`、y 为 `false`。
  ★ 2026-10-01 拿旧办法（`getVisible`）写过一版探针，数轴画出来了却报"没补上"，白追一轮——
  `test/probe_blank.cjs` 现在开头先用两个已知状态自检这把尺子，读数没差别就直接退出码 3。
- **GeoGebra 在 `about:blank` 里加载不起来**（不透明源），但在 `file://` 和 https 下都正常。
  别用 `srcdoc` 或空标签页去承载 applet。
- **`getPNGBase64` 给的是光秃秃的 base64，不是 data URL**（开头就是 `iVBORw0KGgo…`）。
  直接塞 `img.src` 会走 `onerror`，日志里只有一句"画板位图加载失败"，看不出是少了前缀。
  `board.js` 的 `toPNG` / `exportPNG` 都自己补 `data:image/png;base64,`。
- **画板里贴着的那些字（右下角的 `KAX · 数根 mathroot`）`getPNGBase64` 拍不到。**
  它们是板子上的 DOM 层（`index.html` 的 `.wm`），位图里没有。所以「存图」这条路必须
  **自己再画一遍水印**（`exportPNG` 把位图铺进 canvas 再压字）——照位图直接存出去，
  就是一张干干净净、看不出出处的图，而图恰恰是最好搬走、最会外传的那个形态。
  署名的**源头是 `config.js` 的 `SR.COPYRIGHT` / `SR.WATERMARK`**：`main.js` 开机时刷页脚
  和 `.wm`，`exportPNG` 又照 `.wm` 取字——所以改署名只改 config 那两行，
  页脚、画板、导出的图三处一起走。`index.html` 里同样的字是开机前的兜底，别只改那边。
  `test/probe_png.cjs` 守着导出那一处。
- **`fit()` 量的是外面那个盒子（`.boardwrap`），不是 `#ggb` 自己。**
  GeoGebra 的 `inject()` 会把尺寸**写回容器本身**——`#ggb` 上一直挂着行内
  `width: 347px; height: 232px;`。照 `#ggb` 的高度算、再写回 `#ggb`，就成了自问自答：
  量到的永远是上一轮写进去的数，容器每轮再大一点，收敛不了。
  手机上的表现是 applet 232px 塞进 224px 的格子，`#ggb` 是 `overflow:hidden`，底下切掉一条。
- **`fit()` 里那两个下限（240/160）是"别算出 0 或负数"，不是"保证至少多大"。**
  原来写的是 320/240，比手机能给的高度还高——下限一旦高过容器，切掉的就是画板本身。
  而且 `setDefaultView()` 是照这个高度算 y 轴范围的，**方格子会不方**。
- **光听 `window.resize` 不够。** 窄屏顶栏回卷、字体后到改行高，都会让盒子变矮却
  **不触发** `window.resize`。`board.js` 里除了 resize 还挂了个 `ResizeObserver`
  盯着容器本身（带一道"尺寸没真变就别喊 setSize"的闸，防止和 setSize 互相触发）。

### 版面

- **`.brand` 必须写 `flex: 0 0 auto`。** 不写就是默认的 `0 1 auto`，顶栏一挤
  **可以被压到 0 宽**——logo、站名、`by KAX` 一起消失。390px 的手机上就是这样：
  顶栏只剩「学生模式/教师演示模式/关于/Key」，左边露出半截被切掉的 logo。
  这跟"不让人盗用"正好相反：手机上看这一页，页面上根本没写是谁做的。
- **`#thumb` 的 `display:none` 写在样式表里（`main.css:198`），所以显示它要写 `display:block`，
  不能写 `style.display = ''`。** 清空行内样式 = 让样式表说了算，而样式表就是 `none`。
  症状很隐蔽：图上去了、`#thumb img` 也在、探针量到的长度也不为 0，**屏幕上就是看不见**。
  学生的感受是"我拍了照，什么反应都没有"，看不见贴的是哪张，也没法点 × 撤掉。
  ⚠ 同样写法的 `#resbtn`、`#btn-play` 是**安全的**——它们的 `display:none` 在 HTML 的
  `style` 属性里，清掉它就显出来了。**判断"清行内样式能不能显示"要看那条 `display:none` 在哪写。**
- **窄屏顶栏别用 `.brand { flex-basis: 100% }` 让它独占一行。** 剩下的按钮会再排两行，
  顶栏变成三行，最后一行只剩一个「免费通道」，看着像没做完（截到过）。让它自然回卷：
  排得下就排在站名右边，排不下才整块挪下去。（公开站手机上是两行；本机多一个「素材」按钮时会到三行。）

### 提示词 / 模型

- **两个围栏必须写在提示词的最末尾。** 「每一轮都要给三个能点的话」这条原先写在
  提示词四分之一处、后面还压着 147 行，模型看不到它——```想说 的命中率只有 **4/8**。
  挪到最末尾（离学生这句话最近）之后是 **8/8**。演示模式同理：
  「老师说画 xxx 就必须给 ```ggb 围栏」补在结尾，出图率从 **5/8 到 10/10**。
  这是这个作品里最便宜、收益最大的一处改动。
- **演示模式不许塞教材索引。** 学生模式那套索引附注里写着"照上面「三、教材索引」那节的规矩"，
  可演示模式的提示词里根本没这一节，模型被这段没头没尾的附注带跑，
  出图率从 8/8 掉到 6/8。`api.js` 里 `buildSystem` 对 demo 直接返回空。
- **思维链要显式关掉**：DeepSeek 默认会吐 `reasoning_content`，
  带上 `thinking:{type:"disabled"}` 才是 0。万一哪天这个参数不被认了，`api.js` 会自动去掉重发。
- **模型漏围栏是概率事件**，别指望一次实验。`test/probe_fence.cjs` 同一个提示词采样 8～10 次
  数命中率，改提示词前后各跑一遍，才知道动的那一下有没有用。
- **★ 带图片那一轮，模型不是随便挑的。** 免费池三颗视觉模型，同一张"学生错解照片"
  （解方程 2x+1=7，他把 6÷2 写成 4）喂进去，差别是产品级的：
  - `glm-4v-flash`：**把整道题解出来了 4/4**——"正确答案是 x=3，你算错了"。
    **换全量提示词也照解 4/4**，所以这是模型的事，改提示词救不了。
  - `glm-4.1v-thinking-flash`：给答案 3/5，还把自己的思考过程当正文念给学生。
  - `glm-4.6v-flash`：**守得住**，回的是"这道题你当时是怎么做的？从第一步开始说。"
  所以 `config.js` 里图片轮走的是单独的 `modelsImage:['glm-4.6v-flash']`，**链上只有它一颗**：
  再挤也**不许降级**到会解题的那两颗，宁可跟学生说"通道挤了、切自己的 Key"。
  代价是它限流厉害（实测三次成一两次），所以 `api.js` 对单模型链给足重试次数
  （`TRIES = chain.length > 1 ? 2 : 4`），气泡上还给了「再试一次」。
- **判"图有没有送到模型"，别只看气泡里的正文。** 守规矩的模型恰恰**不会**把图上的数复述一遍，
  证据往往在它写的 ```想说 里（"我看移了1到右边"——学生那句话里没提过 1）。
  只判正文 = 谁越界谁得分，会把最守规矩的那一次误判成"图没送到"。
- **提示词里那段示范，小模型会一字不差抄进 ```想说。** 这是示范留在正文里的代价：
  删掉示范，模型连围栏都不写了（4/6 → 0/8）；留着，它就会把示范搬进按钮。
  两边都要，就只能**在出口过滤**：`js/chips.js` 的 `SR.EXAMPLE_CHIPS` 列着提示词里出现过的
  所有例句，命中一句就整组作废、落回本地兜底。
  ⚠ 提示词每换一次示范，这里和 `test/probe_fence.cjs` 的 `EX` 都要跟着改（**两份名单要同步**）。
- **★ 抄的时候它会改几个字，整句比对靠不住。** 2026-10-01 在 DeepSeek 上连打 6 条，
  5 条搬了示范，可只有**每组的最后一句**是一字不差的——前面两句都被改了：

  ——光比"是不是同一个数组"是看不出这个的。
- **掉了围栏的画板命令会被原样念给学生听。** 免费通道那颗文字模型一被要求画图，

  `#清空 ⏎ 数轴 ⏎ A=(-2,0)`、`#隐藏 t`、以及**没带标签的围栏** `… ⏎ ``` ⏎ … ⏎ ``` ⏎ …`
  （成对反引号骗过了"半截围栏"的判断，两个 ``` 会原样印出来）。
  `js/render.js` 现在按三条规则整行删：① 开关命令（`#隐藏 t` 这种带参数的，必须带井号）
  ② 整行只有反引号 ③ **学生模式下**整行就是一条画板赋值（`A=(-2,0)`、`c=正方体(A,B)`）。
  另外还删一种**半截插入语**：④ 提示词里的内部编号被念出来——实测原话
  "**按办法三，**先把空数轴给你。"（"办法一/二/三"是提示词里那三条规矩的编号，
  学生不知道那是什么）。⚠ ④ 只认"带编号又紧跟标点"的，别写成"见着办法/台阶就删"：
  老师正说"我们走到第五台阶"是正常话。
  ⚠ ③ 只在学生模式开：演示模式里老师板书真会写一行 `y=(x+1)(x-2)`，那一行不能删。
  ⚠ 一律只删**整行前后什么都不带**的，老师正文里"我们在数轴上标出 -2"那行不动。
  **这套规则由 `test/probe_render.cjs` 逐条守，每条都配了反例**——因为它删的是学生
  看得见的东西，删错一次在探针里看不出来，只有真人用的时候才炸。
- **删干净之后，气泡会空。** 模型那一轮整段回的都是画板命令时（掉围栏的极端形状），
  删完就一个字不剩了——学生盯着一个空气泡，只会以为页面坏了。所以 `js/chat.js` 在补空图
  之后，如果气泡还是空的，就补一句**程序自己**的话（"画板上给你放了一条空数轴，
  你把题目里那几个数标上去"）：交代的是画板那边的事，不冒充老师提问、不给答案。
  这句话也写进 `history`——下一轮模型才知道画板上已经有东西了，不会又说一遍"你先画"。
  两种毛病要分开报，别混成一格：**画板上没图**（读坐标轴 XML）和**有图但没人说话**（读气泡），
  `test/probe_blank.cjs` 现在两格都判。
- **标签掉了、内容还在，是第三种漏法。** 模型把围栏标签写成光秃秃一个"想说"，
  后面两三行**本该是按钮的话**就直挺挺挂在老师气泡底下了（学生读到"我画不出数轴"这种
  学生口气的话，挂在老师名下）。这跟"回声"是一路坏味道。`js/render.js` 的做法是**收回来用**：
  标签删掉、后面那两三行短句进 `say`，按钮照旧出得来；后面要是拖着一大段话（那多半是正文），
  就只删标签、内容留着——宁可显示，也不能把老师的正文吃掉。

### 前端 / 测试

- **同域普通导航吃缓存。** 改了 `config.js` 之后页面里读出来还是旧值，
  会把「已经生效的改动」误判成「没生效」（今天在这上面白查了一轮）。
  测试一律走 `node test/serve.cjs`（带 `Cache-Control: no-store`），别用 `python -m http.server`
  ——后者只发 `Last-Modified`，浏览器按启发式规则缓存。
- **`isBusy` 要记得在定时器跑完时递减**，只往里塞不移除的话，"画板在画"永远是 true。
  测试脚本里等画板画完不能只看"文字稳了"——逐条出图有 550ms 间隔，文字早稳了图还在长。
- **bad-smell 计数器必须把证据一起打出来。** `probe_fence.cjs` 判"回声"用的是启发式正则，
  同一格跑两次一次 0/6 一次 1/6，可"哪一条被算成回声"没留下——计数器和它宣称的那件事
  之间没有可查的线。加了一行 `↳ 回声原文：…` 之后当场看清：被抓的是
  「好的，你在数轴上标出了-2和1。接下来，你打算比较这两个数的大小吗？」
  ——管对方叫"你"、反问一步，这是**老师好好说的话**，不是演学生；于是把判据收窄成
  "应一声之后必须跟学生口吻"，而不是照着数字去改提示词。
- **红绿要跟着设计走，不能比设计还严。** `学生·求画数轴` 原来要求模型出 ```ggb 围栏，
  可学生模式这条路**本来就设计成靠 `board.giveBlank` 补空图**（免费那颗文字模型守不住围栏，
  实测 0/6~2/6）。围栏那格改成不判红绿，只印出来当信息；真正的验收关在 `probe_blank.cjs`。
  演示模式那三格照旧要 ggb——那是老师在画图，兜底不替它圆场。
- **同一天又栽在同一件事上三次**（2026-10-01），三把尺子量的都不是它宣称的那件事，
  两次差点让我去修没坏的东西、一次差点让我报"3D 做不了平移"：
  - `probe_3d.cjs` 报 `Translate` 过不去，两轮都是**探针自己把命令写错了**：
    它喂的是 `Vector((1,2,3))`（单点）和 `Vector((0,0,0),(1,2,3))`（内联坐标），
    这两种 Vector 都建不出来 → `v` 不存在 → Translate 当然 false。
    改成两个命名点 `Vector(P,Q)` 一次就过。**脚本报红，先看它喂进去的到底是什么。**
  - `e2e.cjs` 的播放键测试把按钮上的字拿 `[^A-Za-z0-9_]` 滤一遍取对象名，
    而模型给滑动条起名叫 `α`——滤完是空串，`getValue('')` 读回 undefined，
    于是报"没动"。画板上转得好好的（采样 0→2.80）。改成取"播放"后面那一段。
  - `probe_image.cjs` 拿"模型有没有复述图上的数"当"图有没有送到"的判据。
    可设计上第一轮它**就该**只问一句"这道题你当时是怎么做的？"，什么都不复述——
    拿复述当判据，等于谁越界谁得分，守规矩的那次反倒被判成通道坏了。
    现在改成读**客户端发出去的请求体**里有没有 `image_url`（硬证据），
    另外先绕开提示词单独问一次"把图上的算式念出来"来单独量通道。
- **别让"预期不过"混进红绿。** `probe_3d.cjs` 里 Prism/Pyramid 要多边形而非散点、
  3D 下只认英文命令名，这些是**已知约束**，留着是为了把约束钉在明处；
  跟"该过的没过"报在一起，两类红就分不开了。用例加了 `want` 字段，只有该过的算红绿。
- **MathJax 太大**（`tex-svg.js` 实测 2.1MB），用 KaTeX。
- **DOMPurify 必须真的调用**，光引入库不 sanitize 等于没防护。

## 借鉴与出处

- **[GeoChat](https://github.com/tiwe0/GeoChat)**（Apache-2.0）——一个 Tauri 桌面版几何作图助手，
  四段流水线（读题→规划→编译→讲解）、55 个内置 `SKILL.md`、一份数值判卷的基准。
  数根**借的是它看问题的轴，不是它的代码**（一行代码都没搬），到目前落在三处：

  | 借来的 | 落在哪 | 变成了什么 |
  |---|---|---|
  | 「自由点 / 依赖对象」这条分界，和"拖一拖还对不对"这个自检 | `js/prompt-draw.js` 的 `# 这张图拖得动吗` | 文字全部按数根自己的量测重写（第 12 题那两个圆碰不上，是本机量出来的） |
  | 把"这张图能不能拖"当成**可量的东西**，不当形容词用 | `test/probe_drag.cjs`、`test/probe_breadth.cjs` 的 ⑤ | 自己写的一套量法：用 `ggbApplet.isIndependent()` 认出自由点，挪一下看谁跟着变 |
  | 把"模型在原地打转"也当成**可数的东西**（它那边的 `nativeConvergenceInstruction`：数"改一次→验一次"的循环，到 4 次提醒、到 6 次硬拦） | `js/converge.js`，在 `js/board.js` 的 `收尾` 里记账、`js/api.js` 的 `buildSystem` 末尾接进提示词 | **改数轮次，不数循环**——数根没有"验证"这个工具，数不了它那个"改一次验一次"。改成数**老师每发一句话算一轮**：这一轮里状态条上说了话（没认／悬空／空壳／哑）就记一次坏；连着两轮，下一句的提示词尾巴上贴「停一下」；三轮贴「这一轮是最后一次修补」。原话全按数根的口气重写（"这几条画板没认""整张重画"），不是它那套 Move/Verify 术语。尺子：`test/probe_converge.cjs`（20 格，两头都量） |

  ★ 有一件**没抄**：GeoChat 的「命令先查后写」那道闸。数根的提示词里已经有一版**带本机实测**的
  （"别编 `点旋转` 这种画板里没有的命令……画板不认识的名字会**整条作废**"），照搬过去是**降级**。
  它另外两样还没借（三色编码、独立修错链），借了就补进这张表。

  ⚠ 抄收敛保护时当场踩到的两个坑，留给下次抄的人（`js/board.js` 的 `收尾` 里写了长注释）：
  ① **别把"记账"放在"这一段到底有没有毛病"还没判出来之前。** `收尾` 每一批画完都会走到那儿，
    画得干干净净的那一批也走。放错位置的结果是**连败每画一张涨一格**——老师连画三张好图，
    照样挨一句「连着 3 轮没画成了」。闸恒开＝这道闸等于没有。
  ② **别拿 `借板中` 去拦"借板那一趟"。** 它在 `fn` 返回时就归 0 了，而 `收尾` 要等
    `setTimeout` 排的命令队列排空才喊——读的时候那个量已经不在了，拦的是空气。
    该钉的是**这一批**的属性（`本批借板`，跟 `步长` 一样在 `run` 开门那一刻量一次）。
  这两条都是 `test/probe_converge.cjs` 当场红出来的，不是想出来的。
